# Roadmap

## 0.1 — Stable Rune foundation

- Establish Rune's independent app identity and attribution.
- Fix repeated onboarding.
- Reset search and navigation state before launching an app.
- Validate installation and Home-role behavior on Android 15.
- Establish the carved-stave visual system without sacrificing readability.

## 0.2 — First fork point

- Add an Internet fork on the east direction.
- Quick release launches the configured default browser.
- A configurable dwell expands Chrome and Firefox child branches.
- Entering a fork and revealing its children produce distinct haptic cues.
- Returning toward the center collapses or cancels the selection.

## 0.3 — Configurable branches

- Allow any primary direction to be an app, system action, or fork.
- Add a setting for **Quick-launch default** versus **Always expand**.
- Make dwell duration and haptic feedback configurable.
- Add an editor for branch labels, icons, apps, and ordering.

## 0.4 — Expansion and portability

- Back up and restore the stave configuration.
- Support Android app shortcuts and selected system actions.
- Evaluate icon-pack support and additional widget behavior.
- Add reproducible signed APK builds through GitHub Actions.

## 1.0 — Stable branching launcher

- Complete accessibility and one-handed-use review.
- Test configuration migrations and process restoration.
- Publish signed, reproducible releases with upgrade documentation.
